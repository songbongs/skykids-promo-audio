# Sky Kids: Starlight Squad — 소개 콘텐츠용 소리

게시판용 HTML 소개 페이지가 jsDelivr로 불러가는 소리 파일 1개만 담은 저장소입니다.

| 파일 | 내용 |
|---|---|
| `skykids-story-v2_bgm-sfx.m4a` | 배경음악 + 효과음 믹스 (60.6초, HE-AAC 28 kbps) |
| `skykids-audio.js` | 위 파일과 같은 소리를 스크립트로 감싼 것 (게시판이 소리 파일 직접 불러오기를 막을 때 사용) |

## 출처
- 배경음악: 직접 작곡·편곡 (칩튠 합성 + GeneralUser GS v2.0.3 음원으로 렌더 — 음악 제작에 제한 없이 사용 가능)
- 효과음: 직접 합성, 일부는 Kenney.nl 효과음 (CC0)
